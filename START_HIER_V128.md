# Optero v0.12.8 — Offerteoverzicht

Deze update voegt een centrale **Offertes**-pagina toe voor de eigenaar.

## Eenmalig in Supabase
1. Open **Supabase → SQL Editor**.
2. Open `supabase/quotes_list_v128.sql` uit deze update.
3. Plak de volledige inhoud in de SQL Editor.
4. Klik **Run**.

Daarna staat onder **Meer → Offertes** een overzicht van alle offertes met klant, status, laatste wijzigingsdatum en totaalbedrag.

De offertegegevens en bedragen blijven alleen toegankelijk voor de eigenaar.
