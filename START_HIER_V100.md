# Start hier — Optero v0.10.0

1. Voer `supabase/transactional_cloud_v100.sql` volledig uit in Supabase SQL Editor.
2. Voer `supabase/VERIFY_V100.sql` uit; alle vijf controles moeten `true` zijn.
3. Plaats de gewijzigde bestanden in GitHub Desktop en push naar `main`.
4. Wacht tot Vercel Ready is.
5. Test: eigenaar maakt afspraak voor een toekomstige datum, wijst monteur toe, logt uit; monteur ziet de afspraak; eigenaar ziet hem na opnieuw inloggen nog steeds.

Belangrijk: voer eerst de SQL uit, daarna de nieuwe frontend deployen.
