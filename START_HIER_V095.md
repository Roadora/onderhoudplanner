# OnderhoudPlanner v0.9.5 — Team-onboarding herbouw

## 1. Eerst Supabase bijwerken
Voer in de SQL Editor het volledige bestand uit:

`supabase/team_onboarding_v095.sql`

Controleer daarna optioneel met:

`supabase/VERIFY_V095.sql`

Beide controles horen `true` te zijn.

## 2. GitHub/Vercel
Vervang daarna de projectbestanden door deze versie. De bestaande environment variables blijven gelijk.

## 3. Test
1. Log in als eigenaar.
2. Nodig een medewerker opnieuw uit.
3. Open uitsluitend de nieuwste e-mail op de telefoon.
4. De link hoort `Activeer je account` te openen.
5. Vul naam en een wachtwoord van minimaal 10 tekens in.
6. De medewerker hoort daarna binnen hetzelfde bedrijf als `Monteur` te openen.

De activatielink is eenmalig en verloopt na zeven dagen.
