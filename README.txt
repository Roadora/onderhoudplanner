ONDERHOUDPLANNER v0.7 PILOT

STARTEN IN VS CODE
1. Pak de zip uit.
2. Open de map in VS Code.
3. Open index.html met Live Server / Go Live.

BELANGRIJK VOOR DE PILOT
- Klanten, systemen en afspraken worden lokaal in de browser opgeslagen.
- Maak via Instellingen regelmatig een volledige JSON-back-up.
- Gebruik steeds dezelfde browser en hetzelfde apparaat, tenzij je een back-up overdraagt.
- WhatsApp-berichten worden vooraf ingevuld, maar niet automatisch verzonden.
- Browsermeldingen worden gecontroleerd wanneer de app wordt geopend.
- Een online account, centrale database en automatische e-mail/WhatsApp horen bij een latere serverversie.

IMPORTEREN
Via Instellingen kun je .xlsx, .xls en .csv importeren.
Download in de app eerst het voorbeeldbestand. Belangrijkste kolommen:
klantnaam, straat, postcode, plaats, telefoon, email, memo, type, merk, model,
serienummer, installatiedatum, interval_maanden, onderhoudsstatus,
laatste_onderhoud, opvolgstatus, onderhoudsprijs.

De import voorkomt zoveel mogelijk dubbele systemen op basis van serienummer of de combinatie klant, merk, model en installatiedatum.
