# v0.9.0 — Rollen & medewerkers

- Eén app met rolherkenning: eigenaar, planner en monteur.
- Medewerkerspagina voor eigenaar/planner.
- Veilige uitnodiging via Vercel Function en Supabase Admin API.
- Openstaande uitnodigingen zichtbaar.
- Teamlimiet van maximaal 5 gebruikers voorbereid.
- Monteur krijgt een aparte mobiele `Mijn dag`-weergave.
- Monteur ontvangt in deze tussenversie nog geen volledige bedrijfsdataset.
- Werkopdrachttoewijzing volgt in v0.9.1.
